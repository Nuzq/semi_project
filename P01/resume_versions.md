# P01 简历项目表述

> 以下为可直接放入简历的项目描述。根据目标岗位选择一版，不需要在同一份简历中重复展示五个版本。

## 项目名称

### 多孔碳材料制备与工艺参数—性能关系研究｜本科科研项目

## 项目事实母版

- 围绕螺旋藻、废弃聚丙烯无纺布及ZIF-8衍生材料开展多孔碳制备研究，涉及前驱体预处理、预炭化/热解、KOH活化、金属盐浸渍及二次热处理等工艺环节，比较热处理温度、活化剂配比等参数对材料结构和电化学性能的影响。
- 整理工艺条件与SEM、XRD、Raman、XPS、BET及CV/GCD/EIS测试结果的对应关系，分析形貌、碳结构、表面组成、孔结构与电化学响应之间的关联，建立“工艺参数—材料特性—测试性能”的分析链路。
- 以螺旋藻和废弃PP无纺布为前驱体的两项研究以第一作者发表论文；论文报告样品比表面积分别为2923.7 m²/g和3838.04 m²/g，比电容分别为348 F/g和340.9 F/g（1 A/g）。

## 1. 材料 / 封装工艺工程师版本

- 梳理前驱体预处理、预炭化、KOH活化及后处理流程，将热处理温度、活化剂配比等定义为工艺输入，将比表面积、孔结构和电化学性能作为材料质量响应，比较不同条件下的结构—性能变化。
- 结合SEM、XRD、Raman、XPS、BET及CV/GCD/EIS结果分析材料形貌、结构、表面组成和孔结构，开展多源表征结果交叉核对，形成从材料制备流程、关键参数到材料特性的分析方法。
- 第一作者论文报告螺旋藻基样品比表面积2923.7 m²/g、比电容348 F/g，PP无纺布基样品比表面积3838.04 m²/g、比电容340.9 F/g（均为1 A/g）。

## 2. 工艺工程师 / 制程工程师版本

- 拆解预炭化/热解温度、活化温度、活化时间及KOH配比等过程输入，关联比表面积、孔结构和比电容等质量特性，整理不同工艺条件下的参数—结果关系。
- 按样品和测试条件关联制备记录、材料表征与电化学结果，区分三电极/两电极体系、测试窗口、电流密度、扫描速率及单位，避免将测试口径差异误判为制程波动。
- 基于历史实验数据建立工艺参数—质量特性复盘框架，输出候选条件的对比依据，具备过程参数拆解、质量特性定义和制程数据复核能力。

## 3. 制造质量 / NPI 工程师版本

- 按“样品标识—工艺条件—表征方法—性能结果”组织材料研究数据，关联论文图表、实验记录及仪器导出文件，提升样品信息、测试条件与结果之间的可追溯性。
- 将比表面积、孔结构、表面组成和电化学性能定义为候选关键质量特性（CTQ），记录对应测试条件、单位和数据来源，识别跨样品、跨测试体系比较中的口径风险。
- 围绕材料制备条件与性能输出建立质量数据审查框架，具备数据追溯、记录一致性检查、指标口径管理和质量风险识别能力。

## 4. 良率 / 测试数据工程师版本

- 整理CV、恒流充放电（GCD）、电化学阻抗（EIS）及循环测试数据，按样品、三电极/两电极体系、测试窗口、电流密度和扫描速率分层，确保同口径数据再比较。
- 将材料制备条件作为过程输入，将比表面积、比电容和循环保持率作为测试响应，建立样品条件、测试条件与性能指标之间的数据关联框架。
- 论文报告螺旋藻体系在10 A/g下循环10,000次后容量保持率94.14%；ZIF-8/Cu体系在1 A/g下循环10,000次后容量保持率99.42%，具备测试条件管理、指标口径核对和测试数据解释能力。

## 5. 失效分析工程师版本

- 按“制备条件—材料结构/表面表征—电化学响应”组织样品分析证据，结合SEM、XRD、Raman、XPS、BET及CV/GCD/EIS结果对照不同样品的结构和性能差异。
- 建立多种表征结果之间的关联核对路径，对样品体系、测试条件、数据来源和结论依据进行标注，区分直接观测结果、性能数据与机理解释。
- 论文报告螺旋藻体系循环保持率94.14%（10,000次，10 A/g）；PP无纺布体系循环保持率超过99.2%（10,000次，10 A/g），具备多表征证据组织、异常线索筛查和数据结论匹配能力。

## 6. ZIF-8衍生材料项目补充版本

### ZIF-8衍生氮/金属共掺杂多孔碳研究｜第二作者项目

- 参与ZIF-8衍生多孔碳研究，涉及ZIF-8静态沉淀制备、氮气气氛800 °C热处理、Cu/Ru盐浸渍及二次热处理等工艺环节。
- 结合SEM/EDS、XRD、Raman、XPS、BET及电化学测试结果分析材料结构、元素组成和电化学性能；论文报告ZC-Cu样品比表面积859.78 m²/g、比电容222.21 F/g（0.1 A/g，三电极）、循环保持率99.42%（10,000次，1 A/g）。
