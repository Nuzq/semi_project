# P02 简历条目（教学模型原型）

基于冻结参数集 `P02-EDU-V1`，已完成硅 PN 结/理想二极管与硅基长沟道增强型 nMOS 解析教学模型原型，生成耗尽层、二极管 I–V 及 MOSFET 输出/转移特性数据和图表。

使用 Python 完成 cm⁻³、cm²/(V·s) 到 SI 单位的显式换算，并以单元测试和数值预检查核对耗尽区电荷平衡、正反偏趋势、MOSFET 工作区边界及分段电流连续性。

**表述边界：**这是基础解析模型与代码自检练习，不是 SiC 产品建模、COMSOL/TCAD 仿真、实验测试、参数敏感性研究或产品性能预测。后续简历版本应按实际岗位和新增完成的工作更新。
