# P02 第一版教学参数冻结记录

**参数集：** `P02-EDU-V1`  
**冻结日期：** 2026-10-23  
**机器可读输入：** [parameters_v1.json](parameters_v1.json)

## 1. 冻结的是什么

冻结（freeze）表示这一版计算使用的输入、单位、公式边界和扫描范围固定下来，使另一个人能够按同一份输入重复运行并得到相同结果。冻结不表示这些数值是实测值、最佳值或真实产品参数。需要改动输入时，保留 `P02-EDU-V1` 原样，并另建参数集版本，记录改动原因。

**本版用途：**用硅（Si）PN 结和硅基长沟道增强型 nMOS 的基础解析方程学习电压如何影响耗尽区、电流和工作区。**这不是 SiC（Silicon Carbide，碳化硅）功率 MOSFET 模型**，也不是 COMSOL 或 TCAD 数值求解。

## 2. 参数分级

“官方常数/材料参考值”表示数值可追溯到权威资料；“教学假设”表示为了演示而选定，并无该器件的测量依据。公式来源不意味着每一个教学输入值也来自该来源。

## 3. 输出方程和术语

- **SI（International System of Units，国际单位制）**：代码把长度统一为 m、浓度统一为 m⁻³、迁移率统一为 m²/(V·s)、电流统一为 A。原始输入写在 JSON 中并带单位；代码负责显式换算。
- **热电压（thermal voltage）**：`Vthermal = kB T/q`。其中 `kB` 是 Boltzmann constant（玻尔兹曼常数），`q` 是 elementary charge（元电荷量）。它是热能的电压尺度，不等于 MOS 阈值电压。
- **内建电势（built-in potential，`Vbi`）**：`Vbi = Vthermal ln(NA ND/ni²)`。`ln` 是 natural logarithm（自然对数）。本式采用热平衡、非简并和完全电离等基础假设。
- **耗尽近似（Depletion Approximation，DA）**：把结区自由载流子近似为很少，只保留固定离化杂质电荷。总耗尽宽度按 `Wdep = sqrt[(2 εSi/q)(1/NA + 1/ND)(Vbi − Va)]` 计算；偏压约定 `Va > 0` 为正向。
- **理想二极管 I–V（Current–Voltage，电流—电压）关系**：`Idiode = IS [exp(Vdiode/(nd Vthermal)) − 1]`。本版用 `expm1` 数值函数在零偏附近提高精度。
- **单位面积栅氧电容（oxide capacitance per unit area，`Cox`）**：`Cox = εox/tox`，单位 F/m²；不要与器件总栅电容混为一谈。
- **费米势（Fermi potential，`φF`）**：本版按 p 型衬底正值定义，`φF = Vthermal ln(NA/ni)`。
- **阈值电压（threshold voltage，`Vth`）**：在 `VSB = 0`（源极—衬底电压为零）下，使用 `Vth = VFB + 2φF + sqrt(4q εSi NA φF)/Cox`。
- **过驱动电压（overdrive voltage，`VOV`）**：`VOV = VGS − Vth`，即栅源电压超过阈值的部分。
- **长沟道 MOSFET I–V（Metal–Oxide–Semiconductor Field-Effect Transistor，金属—氧化物—半导体场效应晶体管）**：强反型模型在 `VOV ≤ 0` 时设 `ID = 0`；`0 ≤ VDS ≤ VOV` 使用线性区关系；`VDS ≥ VOV > 0` 使用饱和区关系。分段边界处电流连续。

## 4. 不在本次冻结/模型中的项目

本版不加入 SiC 材料参数、产品数据手册拟合、亚阈值电流、沟道长度调制、短沟道效应、高场速度饱和、陷阱、体效应、自热、反向击穿或完整温度依赖。虽然 COMSOL 文档提供了硅电子迁移率的温度幂律参数，本次先固定 300 K；使用单一热电压或迁移率变化不能冒充完整器件温度模型。后续如加入上述任一项，应单独注明新增参数与验证依据，并升级模型/参数集版本。

## 5. 来源和交叉核验

- **公式**：MIT OpenCourseWare 6.012 Lecture 4、5、6 支持 PN 结静电、载流子注入及 I–V 基础；Lecture 9、10、11 支持 MOS 电容、阈值和长沟道大信号关系。公式也与项目内 [方程与单位来源表](equation_source_table.md) 逐项对应。
- **物理常数**：NIST CODATA 2022 的 `q`、`kB`、`ε0`，对应来源 ID `P02-T03`。
- **硅参考值**：COMSOL Semiconductor Material Properties 6.3 给出硅相对介电常数 11.7；Power Law Mobility Model 给出硅电子迁移率参考值 1448 cm²/(V·s)、指数 2.33 和参考温度 300 K，对应 `P02-T04`。本版仅采用 300 K 迁移率作为简化模型输入。
- **教学假设**：掺杂、`ni`、`IS`、`nd`、氧化层、`VFB`、沟道尺寸和扫描范围均在 JSON 的 `provenance` 中声明，不伪装成来源论文或厂商实测值。
- **独立检查**：自动测试检查量纲换算、`Vbi` 和耗尽区电荷平衡、零偏/正反偏电流、耗尽区随偏置变化、MOS 截止边界、线性/饱和区连续性。公式来源验证与代码正确性检查是两件事，测试通过不等于模型已由实验验证。

## 6. 如何复现

从 P02 项目目录运行：

```powershell
python -m src.run_model
python -m unittest src.test_p02_model -v
```

输入为 `parameters_v1.json`。脚本输出写入 `data/`、`figures/`，验证记录写入 `results_v1.md`。修改冻结输入前应复制为新参数集，不能静默覆盖本版。
