# 半导体器件与功率器件项目池

最后核验：2026-10-21

## 主攻方向
**半导体器件与功率器件的基础建模、电—热仿真及可靠性数据分析；以SiC MOSFET为主案例，COMSOL做场/热分析，Python做器件模型与数据分析。**

## P02–P07 新定位
| 项目 | 定位 | 工具/输出属性 | 岗位方向 |
|---|---|---|---|
| P02 | PN结与长沟道MOSFET解析教学模型 | Python；解析输出 | 器件建模、应用、测试 |
| P03 | COMSOL一维硅PN结官方基准 | COMSOL Semiconductor Module；数值输出 | 器件仿真、器件工程 |
| P04 | SiC MOSFET简化损耗—热路径模型 | Python+COMSOL Heat Transfer；模型输出 | 功率器件、仿真、应用 |
| P05 | Weibull与寿命指标方法分析 | Python/作者工具；合成教学数据 | 可靠性、质量、测试 |
| P06 | SiC器件测试指标筛查 | Python；合成教学数据 | 测试、产品、可靠性、FA |
| P07 | 多模块证据链综合案例 | 复用P02–P06；不新增实测数据 | 器件应用、可靠性、FA |

优先作品：P02、P04、P05。P03为COMSOL先修，P06为测试岗位扩展，P07最后整合。
